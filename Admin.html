# Admin App এখানে Admin Website-এর frontend থাকবে। পরে একই frontend Capacitor দিয়ে Admin APK হিসেবে প্যাকেজ করা হবে। প্রস্তাবিত পেজ: - Login - Dashboard - Sellers - Products (প্যানেল ও FF ID) - Orders - Manual Payments - Members - Settings শুধু অনুমোদিত admin role-ই অ্যাডমিন ডেটা দেখতে বা পরিবর্তন করতে পারবে। অনুমতি Supabase RLS/server-side logic দিয়ে enforce করতে হবে।

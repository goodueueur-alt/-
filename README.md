# Member App

এখানে Member Website-এর frontend থাকবে। পরে একই frontend Capacitor দিয়ে Member APK হিসেবে প্যাকেজ করা হবে।

প্রস্তাবিত পেজ:
- Login / Sign up
- Home / Products
- Product details
- Checkout / Manual payment
- My orders
- Payment history
- Profile

সেলার অ্যাকাউন্ট অ্যাডমিন তৈরি/অনুমোদন করবে—পাবলিক sign-up থেকে কাউকে নিজে নিজে admin বা seller role দেওয়া যাবে না।
